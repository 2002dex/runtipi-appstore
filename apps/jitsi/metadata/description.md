# Jitsi Meet

Jitsi Meet is a free, open-source video conferencing tool. It lets you host online meetings straight from your web browser or mobile app without making an account or installing extra software. You just share a custom link to invite people.

### Main Features

- **No Sign-up Needed:** Start or join a meeting instantly with a unique web link.
- **Free and Open-Source:** Use the public server for free or install the code on your own server.
- **Collaboration:** Share your screen, send text messages, and edit notes together.
- **Privacy Controls:** Lock rooms with passwords and keep calls encrypted.
- **Custom URLs:** Create easy-to-remember, personalized room links instead of random sequences of characters.
